New to this? Quick glossary
    

  • Pulse / gap: transmitter on / off. A RAW file is just a list of their lengths in microseconds (µs).
    • 

  • Timing guess: pulse/gap widths can suggest PWM or PPM, but do not identify a protocol or prove a decode.
    • 

  • Frame / repeat: remotes send the same message several times per button press. Comparing repeats is how you check a decode.
    • 

  • Fixed vs rolling code: fixed codes repeat identically on every press. Rolling codes change each press, so replaying a saved one won't work.
    • 

  • Cleaned .sub: a normalized OOK estimate. It is not guaranteed to preserve the original signal or replay successfully.
    • 

Tip: capture the same button 3 times, then a different button, and compare the hex. What changes is the button; what stays is the device ID.
